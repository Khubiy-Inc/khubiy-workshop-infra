# KhubiyInc Workshop — Pilot Onboarding Guide

Этот документ — для первого платящего клиента. Что нужно сделать чтобы
начать работу через `https://app.khubiyinc.ru/`.

## Что это

SaaS для управления швейным производством: продажи (клиенты + заказы),
производство (производственные заказы + смены + работники + work-logs),
склад с резервированием материалов по BOM, контроль качества, расчётная
ведомость, отгрузки/возвраты, отчёты. Multi-tenant: каждый цех имеет свой
изолированный «контейнер» данных.

## Первые шаги после регистрации

### 1. Owner входит на `/login`

- Tenant slug, email, password — из welcome-письма
- Поменять пароль (TODO в UI — сейчас через support)

### 2. Настроить структуру цеха

В таком порядке:

**A. `/catalog` → Sections**
Участки цеха (Раскрой / Пошив / Отделка / Упаковка). Уже создан seed —
можно использовать или удалить и завести свои.

**B. `/catalog/brigades` → Бригады**
Группы работников внутри section'а. Используются в auto-assign для skill-фильтра.

**C. `/employees` → Сотрудники**
Создавай:
- **Office** (Менеджер / Бухгалтер / Мастер смены) — указать email,
  ему придёт инвайт-письмо (когда подключим email-провайдер).
- **Worker** (Швея / Раскройщик / ОТК) — поставить галку
  «Выпустить QR-бейдж» — backend сразу выпустит QR. Покажи его работнику,
  он сканирует через мобильное приложение или kiosk `/worker/login`.

**D. `/settings/roles` (только Owner)**
Выдай office-сотрудникам нужные роли:
- `manager` — управление продажами, производством, инвентарём, отгрузками
- `accountant` — payroll, payments, reports
- `shift_master` — смены + задачи + work_logs (через мобильный office tab)

### 3. Каталог продукции

**A. `/catalog` → Operations**
Операции с базовой ставкой (норма-минуты + ₽). Используются в tech-card
маршрута.

**B. `/catalog` → Materials**
Сырьё с ценой и единицей измерения. Для BOM tech-card.

**C. `/catalog` → Products**
Продукция с фото, артикулом, размерной шкалой.

**D. Tech-card** для каждого продукта:
- Routing (последовательность операций с нормами/ставками — snapshot
  при создании PO)
- BOM (материалы с qty_per_unit + waste_pct — резервируются при confirm заказа)

### 4. Параметры тенанта `/settings/tenant`

- **Task assignment mode**: `manual` (ручной выбор работника на каждую задачу) /
  `auto_on_open` (автораспределение при открытии смены) / `both`.
- Auto-assign использует skill (employee.grade ≥ operation.required_grade)
  + load-balancing (round-robin от менее нагруженных).

### 5. Первый заказ end-to-end

**A. `/orders` → «Создать»**
- Клиент (если нет — `/clients` → создать)
- Позиции (product + size + color + qty + price)
- Опционально: канал продаж (`/settings/sales-channels` → создать) +
  прайс-лист (`/settings/price-lists` → tier pricing)

**B. Конвейер статусов**:
- draft → **Подтвердить** → confirmed (резерв материалов)
- confirmed → **В производство** → in_production (создаётся PO + routings)
- в работе: смены / задачи / work_logs (см. ниже)
- in_production → **На ОТК** → qc
- qc → **Упаковка** → packing
- packing → **Отгрузка** → shipped (создаётся shipment)
- shipped (терминальный)

В любой момент: `Hold` (приостановить) или `Cancel` (отменить).

**C. Производство**:
- `/shifts` → создать смену → перевести `planned → open`
- На странице смены — кнопка «Назначить задачу» или «Авто» (если включил
  auto-assign в `/settings/tenant`)
- Работник на планшете/мобильнике вводит факт работы → создаётся work_log
- Дефекты → `/defects` (или сразу из work_log entry формы)

**D. Финансы**:
- `/orders/:id` → раздел «Платежи» — добавлять предоплаты / финальные оплаты
- `/payroll` → создать период (например, за прошлую неделю) → калькуляция
  по work_logs → утвердить → провести оплату

## API для интеграций

`/settings/api-keys` → создать ключ с нужными scope'ами:
- `catalog:read` — просмотр товаров/операций/материалов
- `orders:read` — просмотр заказов
- `orders:write` — создание заказов (для интеграции с CRM)
- (расширим список scope'ов по запросу клиентов)

Public API: `https://app.khubiyinc.ru/api/v1/public/...` (требует
`X-API-Key: <key>` header).

Webhooks (`/settings/webhooks`): создать endpoint → события (`sales_order.created`,
`sales_order.shipped`, и т.д.) шлются на твой URL с HMAC-подписью.
